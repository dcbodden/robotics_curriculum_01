# Lesson 02: Manual Voltage Mapping

In this standalone, non-code lesson, you will measure changing voltage and use a lookup table to sort each reading into one of eight digital levels. Each decimal level from 0 through 7 has a matching 3-bit value.

## Learning Goals

By the end of the lesson, you will be able to:

- measure several points along a changing voltage range;
- use a lookup table to choose a decimal level;
- match each decimal level with a 3-bit value; and
- explain how many nearby voltages can share the same digital level.

## Student Instructions

1. Read the safety and wiring directions your teacher provides before connecting or powering any parts.
2. Ask your teacher to check the unpowered voltage-divider circuit.
3. After teacher approval, measure the voltage at each requested control position.
4. Use the lesson's voltage-range lookup table to find the decimal level and 3-bit value for each reading.
5. Record the minimum, maximum, and at least six additional readings in [`recording-activity.md`](recording-activity.md). Make sure your completed table includes every level from 0 through 7.
6. Compare your readings and answer the reflection questions in your own words.

This lesson uses the Arduino only as a source for the lesson's low voltage. It does not require programming, building firmware, or uploading firmware.
