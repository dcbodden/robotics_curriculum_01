# PlatformIO ESP32 Robotics Template

This directory contains an advanced PlatformIO-based ESP32-WROOM-32 curriculum template centered on:

- the OV7670 camera for video and perception experiments
- the DRV8833 motor driver for mobility and control

It is subdivided into two projects:

- `fpv-wifi-rc-car/` — a first-stage Wi-Fi-controlled FPV robotics platform
- `semi-autonomous-robotics/` — a follow-on robotics platform that builds on the RC car mobility base
