# PlatformIO Uno Template

This directory contains a starter PlatformIO project for VS Code using:

- platform: `atmelavr`
- board: `uno`
- framework: `arduino`

## For Lesson Authors

Copy this template into a new numbered directory under [`platformio-uno-lessons/`](../platformio-uno-lessons/) when creating a hardware/software lesson. Give the new lesson its own `platformio.ini`, source code, and student instructions so it can be opened and built independently.

Do not place several lessons inside this template or build the template as though it were the lessons collection. The template remains a clean starting point.

## For Students

Open an existing project from the separate [`platformio-uno-lessons/`](../platformio-uno-lessons/) collection instead of this template. Start with [`01-gpio-transistor-switch`](../platformio-uno-lessons/01-gpio-transistor-switch/), which uses Arduino Uno digital pin 8 to control an existing transistor-and-LED assembly.
