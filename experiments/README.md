# Experiments

Use this directory for self-contained experiment artifacts, for example:

- Snap Circuits activities
- breadboard wiring diagrams
- experiment handouts
- observation or reflection sheets tied to a single lesson

## Standalone projects

- [ESP32 Bluetooth Controller Baseline](esp32-bluetooth-controller-baseline/README.md) — tests an ESP32-WROOM connection to a Mystiluck/Senze SZ-4015B controller in PS4-compatible mode and provides structured serial diagnostics for pairing, reconnection, and controller input.
