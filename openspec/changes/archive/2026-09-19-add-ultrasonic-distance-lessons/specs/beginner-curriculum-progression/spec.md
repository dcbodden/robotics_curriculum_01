## MODIFIED Requirements

### Requirement: Canonical beginner learning route
The curriculum SHALL present one primary beginner route in the repository guide and relevant collection indexes: multimeter foundations, coding fundamentals, the first Arduino digital-output circuit, Arduino ADC variable delay, manual voltage-mapping reinforcement, PWM motor control, responsive interrupt-driven control, coordinated joystick motor/servo control, blocking ultrasonic distance measurement, interrupt-driven ultrasonic measurement with continued joystick control, and distance-aware motor slowdown. Optional activities SHALL be identified without contradicting prerequisites on the primary route.

#### Scenario: Plan the beginner sequence
- **WHEN** a teacher follows the primary route from any linked curriculum index
- **THEN** each next activity satisfies the prerequisites stated by that activity and matches the order shown by the other indexes
