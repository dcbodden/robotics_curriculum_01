# Proposal: bootstrap curriculum layout

## Why

The repository currently has only a README and does not yet provide the structure needed for curriculum documents, experiments, or Arduino lesson projects.

## What Changes

- add the initial top-level curriculum directories
- add a PlatformIO Arduino Uno starter template for VS Code use
- add lightweight OpenSpec artifacts to document the repository structure

## Impact

- contributors can place materials in predictable locations
- lesson projects have a reusable starter template
- future structural changes can follow an OpenSpec workflow
