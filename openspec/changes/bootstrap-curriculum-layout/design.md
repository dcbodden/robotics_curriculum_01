# Design

The repository remains intentionally lightweight:

- each requested top-level area is represented by a clearly named directory with a README
- the PlatformIO starter project uses the default `src/` layout and a minimal blink sketch
- the ESP32 robotics area uses a parent directory with two focused PlatformIO subprojects
- OpenSpec support is limited to a small `openspec/` tree plus `AGENTS.md` guidance instead of a full generated framework
